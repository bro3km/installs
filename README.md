## Skripte
Installieren nur, was noch fehlt (immer die neueste Version). Vor jedem Paket wird nachgefragt, mit `-y` nicht.

**Arch Linux** (installiert `yay`, falls nötig):
```bash
bash install-arch.sh        # mit Rückfragen
bash install-arch.sh -y     # ohne Rückfragen
```

**Windows** (über `winget`):
```powershell
.\install-windows.bat        # oder: powershell -ExecutionPolicy Bypass -File .\install-windows.ps1
.\install-windows.bat -y
```

Menü: `1` Alles installieren · `2` Kategorien installieren · `3` Kategorien löschen · `4` Abbrechen
